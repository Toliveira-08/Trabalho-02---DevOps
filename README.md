# Trabalho 02 - DevOps

Projeto-base para atividade prática de colaboração e versionamento de código com Git e GitHub.

## 🎯 Objetivo

Evoluir uma página web existente por meio de trabalho colaborativo.

## 🛠️ Tecnologias e Arquivos Base

- **HTML5** (`index.html`) – Estruturação da página do portal acadêmico
- **CSS3** (`style.css`) – Estilização e layout base
- **JavaScript** (`script.js`, `funcoes.js`, `teste.js`) – Funcionalidades, scripts de interação e testes
- **GitHub Pages** – Hospedagem do projeto online
